# South Fulton publisher policy and service context

The city's normally acquired crawler policy has seven groups, including a
multi-agent AI/search group with path restrictions. It is not a universal AI
denial. The previous strict parser rejected the unsupported layout. An explicit
reviewed layout now retains all wildcard and named restrictions together.

## Conservative grouped rules

This opt-in mode intersects the wildcard and every applicable reviewed group.
An allowance in one group cannot override a denial in another. All groups are
parsed, including the five explicitly recognized unrelated crawler identities,
and their longest crawl delay applies. AI, wildcard and unknown identities cannot
be marked unrelated. Missing, added, duplicated or reordered headers, malformed
rules and excessive delays fail closed. Configuration and original policy hashes
remain part of the current access review.

The approach is deliberately more restrictive than ordinary group selection in
[RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html). It changes neither the
request identity nor existing source defaults, host limits, publisher holds,
expiry, content bounds or private import/publication/scheduling gates.
