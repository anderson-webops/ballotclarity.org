## Policy, future cycles and persistence

The normal robots response is a reviewed 404, not a denial. Only that exact absence
is supported. New rules, redirects, denials and throttling stop for review without
weakening other source gates. The complete footer/legal-link inventory is bound
on each page. The linked [accessibility statement](https://dcboe.org/Accessibility)
describes Section 508 and has a separately bound main-content fingerprint. It
contains no website-reuse restriction. No blanket content license is claimed;
only attributed candidate facts are normalized.

Discovery uses actual offered year pages and printed general-election dates.
All three publication types are required. Incomplete future sets remain pending;
complete supported publications can import without annual URL edits. Synthetic
2028 fixtures test compatibility, not an actual candidate roster or predicted
ballot. Unknown offices, parties, geometry, incomplete XML/pages and changed
policy remain review exceptions.

The bounded worker uses an explicitly configured maintained `pdftotext` path,
serial eleven-second spacing, zero redirects and standard TLS/public-address
validation. Persisted reads are converter-independent. Original PDF hashes and
URLs bind the index so same-URL revisions trigger refresh. Missing accepted
identities or complete publications require review rather than silent removal.

The first automatic replacement saves the exact reviewed envelope. Failed backup,
collection or persistence retains accepted data and truthful clocks. Older-runtime
data recovery retains that reviewed contract. Ward and ANC-SMD labels never become
unverified Census districts; federal/shadow citizenship restrictions remain.
Reference packets, source publication, scheduling and production acceptance are
distinct outcomes. Originals and private data stay outside release assets.
